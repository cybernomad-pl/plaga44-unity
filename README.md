# PLAGA '44 — Unity VR Survival Game

Post-apocalyptic VR survival game set in Jura Krakowsko-Czestochowska, year 2144.
Target platform: Meta Quest 2/3/3S.

## Status: Initial Setup

- Engine: Unity 6.3 LTS (TBD - project will be opened in Unity Hub first)
- Render Pipeline: Default (will configure URP later)
- XR: Not configured yet

## Getting Started

1. Clone this repo
2. Open in Unity Hub
3. Let Unity import and generate project files

## Structure

- `Assets/Scripts/` — C# game scripts
- `temp/` — Asset recycling bin (gitignored)
