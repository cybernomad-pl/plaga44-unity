How to Use

  1. Generate a 3D model using pipeline/turntable_pipeline.py
  2. Find your model at assets/output/your_model/final/model.glb
  3. Click "Choose GLB/GLTF File" or drag & drop onto viewer
  4. Use mouse to rotate, scroll to zoom, right-click to pan
  5. Try example models above to see how it works
