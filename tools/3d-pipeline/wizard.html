Step 5: Ready to Process

Your configuration is ready. Follow the steps below to generate your 3D model.

Next Steps:

1. Copy your files to input directory:

cp your-file.mp4 cbrnmd.3D/assets/input/

2. Run the pipeline:

cd cbrnmd.3D
python pipeline/turntable_pipeline.py --input assets/input/your-file.mp4 --output assets/output/my_model

3. View your model:

python -m http.server 8000
# Open: http://localhost:8000/viewer.html
# Drag & drop: assets/output/my_model/final/model.glb
