   | Menu:                     |       | Menu:                        |
   | PLAGA44/Setup/            |       | PLAGA44/Setup/               |
   | Apply Predator Hands      |       | Revert Predator Hands        |
   +-------------+-------------+       +--------------+---------------+
                 |                                    |
                 v                                    v
   +---------------------------+       +------------------------------+
   | Apply():                  |       | Revert():                    |
   |  1. ResolveMaterial()     |       |  1. Foreach hand renderer    |
   |     -- podpina shader     |       |  2. Odczyt backup path       |
   |        po nazwie jesli    |       |     z EditorPrefs            |
   |        GUID missing       |       |  3. Przywroc material        |
   |  2. FindHandRenderers()   |       +------------------------------+
   |  3. Backup sharedMaterial |
   |     do EditorPrefs        |
   |  4. r.sharedMaterial=mat  |
   +---------------------------+

  FindHandRenderers():
    for each Transform T in scene:
      if T.name contains "StylizedCharacter":
        for each Renderer R in T.children:
          if R.name.ToLower() contains "hand":
            yield R
