======================================================================
                          LOCOMOTION
======================================================================

  L THUMBSTICK = head-relative movement
    Blocked in: Paused (menu), Prone stance

  R THUMBSTICK Y-AXIS:

    GROUNDED + STAND:
      ┌─────────────────────────────────────────────┐
      │  UP held = ASCENDING (accelerating flight)  │
      │  DOWN tap = cycle: STAND -> CROUCH -> PRONE │
      │  UP tap (from crouch/prone) = cycle up      │
      └─────────────────────────────────────────────┘

    FLY STATE MACHINE:
      GROUNDED ──[stick UP + Stand]──> ASCENDING
        _flySpeed += flyAcceleration * dt (increasing)
        _verticalVelocity = _flySpeed
        gravity OFF

      ASCENDING ──[release]──> HOVERING
        _verticalVelocity = hoverDrift (random +-0.3 m/s)
        drift target changes every 1-3 sec, smooth lerp
        gravity OFF, player floats

      HOVERING ──[stick UP]──> ASCENDING (boost)
      HOVERING ──[stick DOWN]──> GROUNDED (drop, gravity ON)
      any ──[land]──> GROUNDED

    STANCE (ground only, not flying):
      DOWN tap: STAND -> CROUCH -> PRONE (cycle)
      UP tap:   PRONE -> CROUCH -> STAND (cycle)
      Edge detection: one trigger per stick push

      SMOOTH TRANSITIONS (no snap, no VR sickness):
        CC.height     = MoveTowards(current, target, speed*dt)
        CC.center.y   = h * 0.5
        TrackingSpace.y = MoveTowards(current, target, speed*dt)
        stanceTransitionSpeed = 3 m/s

      Heights:  STAND=1.8  CROUCH=1.0  PRONE=0.5
      PRONE blocks horizontal movement

    MENU (Paused):
      CanMove = false
      No movement, no turning, no fly, no stance change
      Player can only use menu controls
