═════════════
  GameState.Current = Playing (default)
  CanMove = true, IsPlaying = true

  LocomotionController.Update():
    if !GameState.CanMove return
    Read L thumbstick → head-relative move
    Read R thumbstick Y:
      → UpdateFly: state machine (Grounded↔Ascending↔Hovering)
        Entry to Ascending: SetStance(Floating)
        Exit (EndFlight): SetStance(Stand)
      → UpdateStance: cycle Stand/Crouch/Prone (only when Grounded)
      Safety: if flying && stance != Floating → force Floating
    if Grounded: ApplyGravity
    CC.Move(horizontal + vertical)

  SmoothTurnController.Update():
    if !GameState.CanMove return
    R thumbstick X → rotate rig Y

  HamburgerMenu.Update():
    Start button → toggle Pause/Resume
    Menu open: GameState.Pause()
      timeScale stays 1 (SDK hands keep animating!)
      CanMove = false, IsPlaying = false
      → Locomotion + SmoothTurn block themselves

    grip flex >= 0.55 → StartGripHold (continuous buzz)
