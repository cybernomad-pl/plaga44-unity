PLAGAGRABBER -- GRAB TOGGLE + FORCE GRAB
============================================================================

  Awake:
    grabEnd = -1f       // blokuje hold-to-release z OVRGrabber base

  GrabBegin (override):
    m_grabbedObj != null ?
      Y -> GrabEnd                    // toggle release
      N -> base.GrabBegin()           // toggle grab z candidates

  ForceGrab(target)   <-- NOWE
    target == null             -> warn, return false
    target.isGrabbed && !allow  -> warn, return false
    m_grabbedObj != null       -> GrabEnd (release previous)
    m_grabCandidates.Clear()
    m_grabCandidates[target] = 1
    GrabBegin()                // our override -> m_grabbedObj==null -> base
