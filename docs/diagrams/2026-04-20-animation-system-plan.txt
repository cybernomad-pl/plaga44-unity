-----------------------------------------------------------------------------
 ANIMATOR CONTROLLER (PLAGA44_PlayerAnimator.controller)
-----------------------------------------------------------------------------

 Parametry:
   Speed        (float, 0..2)    -- linear speed magnitude
   IsFlying     (bool)            -- rightY > threshold AND grounded=false
   IsFreefall   (bool)            -- StratoJump active (wysoko + !grounded)
   Trigger:Land (trigger)         -- puls gdy grounded zmienia na true

 Layers:
   [0] BaseLayer (weight=1)
       States:
         Idle          -- Idle.fbx (looping)
         Locomotion    -- blend tree (1D, Speed):
                          0.0 -> Idle
                          1.0 -> Run.fbx (plus strafe na lateral)
                          2.0 -> Run.fbx (faster playback)
         Fly           -- falling idle.fbx (looping, modified upper)
         Freefall      -- falling idle.fbx (looping, forced full body)
         Landing       -- falling to roll.fbx (one-shot, 0.5s, triggered)

       Transitions:
         Idle        -> Locomotion   [Speed > 0.1]
         Locomotion  -> Idle         [Speed < 0.05]
         Any         -> Fly          [IsFlying == true]
         Fly         -> Idle         [IsFlying == false, grounded]
         Any         -> Freefall     [IsFreefall == true]
         Freefall    -> Landing      [grounded edge (Trigger:Land)]
         Landing     -> Idle         [exit time = clip length]

-----------------------------------------------------------------------------
 CHARACTER RETARGETER (processor weights per state)
-----------------------------------------------------------------------------

  _targetProcessorContainers (indeks, typ, opis):
    [0] Twist           -- twist bones correction, zawsze Weight=1
    [1] Animation       -- HIPS (y-sync z freefall/fly, x-z z tracking)
    [2] Animation       -- LOWER BODY (nogi, stopy)
    [3] Animation       -- UPPER BODY (spine, head) -- NORMALNIE Weight=0
    [4] CCDIK           -- LeftHand IK -> controller L
    [5] CCDIK           -- RightHand IK -> controller R

  Weights per state:

              | [1] Hips | [2] Lower | [3] Upper | [4/5] Hands IK |
  ------------+----------+-----------+-----------+----------------+
  IDLE        |   0.0    |    0.0    |    0.0    |    1.0         |  (pure tracking)
  LOCOMOTION  |   1.0    |    1.0    |    0.0    |    1.0         |
  FLY         |   1.0    |    1.0    |    0.0    |    1.0         |
  FREEFALL    |   1.0    |    1.0    |    1.0    |    0.0         |  (forced pose)
  LANDING     |   1.0    |    1.0    |    1.0    |    0.0         |

 CAMERA CONTROL (Freefall look-down)
-----------------------------------------------------------------------------

  Problem: OVRCameraRig naped zaszyty, nie mozemy nadpisac kamerze rotacji
  (Quest tracker wymusza realna rotacje gracza).

  Rozwiazanie (opcja A): 2 kamery, blend
    - Gracz w Questcie nadal krec glowa normalnie
    - Druga wirtualna kamera "Freefall camera" z pitch -60
    - Blend pomiedzy nimi przez canvas fade / post-processing lens warp

  Rozwiazanie (opcja B, PROPOSED): tilt OVRCameraRig root podczas Freefall
    - Rig.rotation = Quaternion.Euler(freefallPitch, yaw, 0)
    - freefallPitch = 60 (lookdown). Gracz patrzy "w dol" wzgledem world.
    - Po lądowaniu: fade pitch -> 0 przez 0.5s
    - Naturalne dla skydive: patrzysz w dol widzisz ziemie

 FreefallCameraController.cs:
   void LateUpdate() {
     if (state == Freefall) {
       targetPitch = Mathf.Lerp(targetPitch, 60, Time.deltaTime * 2);
     } else {
       targetPitch = Mathf.Lerp(targetPitch, 0, Time.deltaTime * 3);
     }
     rig.transform.rotation = Quaternion.Euler(targetPitch, currentYaw, 0);
   }
