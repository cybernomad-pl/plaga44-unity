═══════════════════════════════════════════════════════════════════
  FLOW -- USER STORY
═══════════════════════════════════════════════════════════════════

  Gracz otwiera menu -> GAMEPLAY -> ITEMS -> slider -> wybiera Revolver
     ↓
  ItemBrowser.SetItem(1) -> SpawnPreview
     ItemPreview_Revolver pojawia sie 1.2m przed graczem na stole
     [eye level offset y=-0.5m]
     ↓
  Gracz chwyta grabem (L lub R grip) -> PlagaGrabber.GrabBegin (toggle)
     ↓
  PlagaGrabbable.GrabBegin(hand):
     _holdingController = L/RTouch
     ItemGripConfig.Load("Revolver")  -- z PlayerPrefs lub Default
     ApplyGripConfig:
       transform.localPosition = cfg.offsetPos
       transform.localRotation = Quaternion.Euler(cfg.offsetRotEuler)
       transform.localScale = _originalScale * cfg.scale
     HandFingerFreezer.Freeze(ctrl, fistPose:false):
       cache Transform -> localRotation dla 15 finger bones
       LateUpdate applies them every frame after SDK retargeter
     ↓
  Gracz otwiera menu -> GAMEPLAY -> ITEM GRIP
     ↓
  Ruch suwakiem "Pos X" -> SettingsRegistry setter:
     c = findTarget.GripConfig (struct copy)
     c.offsetPos.x = v
     write(c) -> target.GripConfig = c
       -> setter -> ApplyGripConfig(c)
       -> transform.localPosition updated LIVE in hand
     ↓
  Gracz widzi zmiany realtime. Dopasowuje -> klik "SAVE GRIP":
     ItemGripConfig.Save("Revolver", currentCfg)
     -> PlayerPrefs zapisane (posX/Y/Z, rotX/Y/Z, scale)
     -> SetAction: "ITEM GRIP SAVED for 'Revolver'" (banner)
     ↓
  Gracz puszcza grab (grip toggle):
     PlagaGrabbable.GrabEnd:
       HandFingerFreezer.Unfreeze(ctrl) -- palce wracaja do SDK tracking
       base.GrabEnd -- normal physics drop
     ↓
  Next session: gracz bierze Revolver -> GrabBegin -> Load("Revolver")
     -> saved offset applied automatycznie
